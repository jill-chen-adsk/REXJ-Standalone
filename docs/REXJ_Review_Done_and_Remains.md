## Four pillars — achievement vs gap

### 1 · Product catalog — **Delivered** (90%)

**Sub:** Feature summary with Tetsuya (Hishida)  
**Roadmap:** Foundation for Levers 2–4

**Achievements**

- Documented all 38 REXJ tools — purpose, workflow, customer value
- Created shared language for PM, Japan team, and leadership
- Enabled usage analytics to map to named tools (not anonymous add-on)

**Gaps remaining**

- Tool-level ownership not yet tied to promote / retire decisions
- Internal teams still lack lightweight entry point for tool discovery

### 2 · Adoption analytics — **Delivered** (85%)

**Sub:** Looker / extension dashboards  
**Roadmap:** Informs Lever 4 (Retire) + Lever 2 (Promote)

**Achievements**

- Overall REXJ adoption trends (MAU, CSAT — 2,705 MAU FY27 Jun, 4.0 CSAT FY26)
- Adoption by company — concentration vs design-firm gap surfaced
- Per-tool usage — which of 38 tools earn maintenance cost

**Gaps remaining**

- Analytics → roadmap decisions not yet on a quarterly cadence
- Low-usage tool sunset list not leadership-approved

### 3 · Operating model — **Blocked** (55%)

**Sub:** Dev · maintenance · delivery process  
**Roadmap:** Lever 1 — Streamline Dev & Delivery

**Achievements**

- Mapped 7-step manual release pipeline (Hayashi → Paul → Arent → AppStore)
- Quantified 3× effort per Revit version; automation feasibility assessed
- Process optimization report + staffing options (4 paths) published
- Japan local contractor (Arent) engaged on improvements

**Gaps remaining**

- Internal engineering validation — no team prioritized to support
- Release cadence still not aligned with Revit annual ship
- Automation/testing bar undefined with engineering sign-off
- Staffing decision (Option 1–4) not closed

### 4 · Recharge — English visibility — **Delivered** (75%)

**Sub:** Internal globalization via recharge sprint  
**Roadmap:** Enables Lever 2 + Lever 3 discovery

**Achievements**

- English UI across menus, dialogs, exports — any locale can install internally
- Weave modernization on selected tools; GitHub releases + changelogs
- AI-assisted delivery model proven (PM-led, no C# expertise required)
- Internal teams can now evaluate REXJ for promote-to-core / agentic mapping

**Gaps remaining**

- Cross-team outreach depends on bandwidth
- Customer-facing globalization (EN/JA/ZH) is a separate track
- Feedback loop from internal evaluators not structured yet
